# Foto

Metti qui le immagini del sito. Nomi attesi dal file `index.html`:

| File | Formato | Cosa |
|---|---|---|
| `ritratto.jpg` | verticale 4:5 (es. 1000×1250) | Il tuo ritratto, sezione Profilo |
| `seeker-ii.jpg` | orizzontale 4:3 (es. 1200×900) | Foto del razzo o render CAD |
| `edunity.jpg` | orizzontale 4:3 (es. 1200×900) | Schermata dell'app |

Dopo averle messe qui, in `index.html` cerca `TODO FOTO`: cancella il blocco
`<div class="plate…">` e togli il commento all'`<img>` che sta subito sopra.

Consigli: esporta in JPEG qualità 80, larghezza massima 1400 px. Sopra i 300 KB
per immagine il sito inizia a rallentare da telefono.
